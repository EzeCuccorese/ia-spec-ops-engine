# SpecOps Rules

Autonomous Software Engineering Standards Catalog & Multi-Agent Reversible Injector for AI Coding Agents.

## Features
- **28 Canonical Engineering Rules**: Clean Code, SOLID, DDD, Clean/Hexagonal Architecture, Testing Patterns, Security OWASP, Resilience, Concurrency, Git Commits, and modern language stacks.
- **Interactive TUI**: Simple, clean terminal menus to select scopes, agents, and rule groups with mass "Select All" support.
- **Reversible Ingestion**: Injects bounded reference blocks into `AGENTS.md`, `CLAUDE.md`, `.cursorrules`, etc., without ever modifying or corrupting user notes.
- **On-Demand Context Loading**: Generates native `.cursor/rules/*.mdc` with globs and trigger indices to prevent burning context window tokens.
