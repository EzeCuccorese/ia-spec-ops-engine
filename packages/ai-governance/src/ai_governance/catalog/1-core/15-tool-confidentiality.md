# Tool Confidentiality

## Invariants
- **Confidential Tooling**: Never mention engine tools (`ai-governance`, `ws`, `taskflow`, gates, `QG_SKIP`, hooks, scripts, or orchestrators) in tickets, PRs, commits, reviews, Confluence, or chats.
- **Corporate Confidentiality**: In company work artifacts, never name the engine, its repository, or its internal tools. Describe only the company product, behavior, and code changes.
