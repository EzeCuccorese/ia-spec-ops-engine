# Ejemplos

```bash
progress new payment --title "Pago idempotente"
progress step payment add "Escribir tests"
progress fact payment "Baseline verificado"
progress view payment --json
```

```bash
ws hooks install
ws hooks run --scope changed
ws hooks run --output verbose
```

```bash
spec work
spec test-assist --next
spec verify --json
```

`spec finish` requiere evidencia `PASS` y confirmación humana.
