03 / Neural + Deterministic Architecture

Orca runs the workers. The Engine owns the rules and memory.

The engine never replaces Orca or spawns agents on its own: it prepares specs, prints the exact orca orchestration worker-start command, and verifies results when Orca finishes.

Orca · Execution Layer

Clean worktrees and coordination without manual polling

Orca creates and isolates each worker's workspace, wakes your coordinator session on worker_done, and writes the signed launch.json receipt that the Engine audits. 

# The Engine builds the spec and gives you the exact Orca command:
orca orchestration worker-start --spec-file .../runs/001/spec.md \
  --agent antigravity --model gemini-3.8-flash --effort low \
  --worktree path:/your/repo --task-title 'debater round 1' --json > launch.json

08 / Team Reliability

Internal safeguards so nothing fails silently

When multiple devs run Orca workers in parallel, edge cases happen. The Engine is fail-closed: when in doubt, it stops cleanly and explains exactly why.

Model Policies

denied_models + --effort

  • A repository can never relax the user's denied-model list; it can only add to it.
  • If config is malformed or the model is missing in Orca's launch.json, collect rejects the round.
  • --effort is always validated alongside an explicit or default model.
Concurrency & Rollback

Separate locks and zero disk clutter

  • Dedicated .debate.lock separate from store .lock (no deadlocks).
  • Non-blocking reads on regular files only (O_NONBLOCK + S_ISREG).
  • If an Orca dispatch fails mid-flight, rounds and seals are rolled back.
Team payoff: nobody has to memorize a dozen flags; the repo and your local config enforce the same rules on every Orca worker.

10 / Get Started in 2 Minutes

How to install and use it in your Orca setup

Each teammate installs both packages once with uv tool, enables non-intrusive hooks, and can launch rounds or debates straight from their Orca session. 

# 1. Install both CLIs from the repo (editable if using local packs/skills)
uv tool install --editable ./packages/ai-governance
uv tool install --editable ./packages/workspace

# 2. Install agent rules and repo pre-push hooks
ai-governance install --scope user --agent claude --agent codex --agent antigravity
ws hooks install

# 3. Verify everything is healthy and ready for Orca
ai-governance doctor && ws doctor

# 4. Start your first multi-provider debate from Orca
ai-governance taskflow new my-design --title "Define cache strategy"
ai-governance taskflow debate my-design open --topic-file topic.md --agents claude,antigravity --web
