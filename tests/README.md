# Suite de Pruebas Automatizadas (`tests/`)

Harness centralizado de pruebas automatizadas para todo el sistema `devscripts`.

## 📁 Subdirectorios

- **[`unit/`](file://~/projects/devscripts/tests/unit):** Pruebas unitarias para capas de core, servicios y utilidades CLI.
- **[`integration/`](file://~/projects/devscripts/tests/integration):** Pruebas de integración para sincronización de toolkit, borrado seguro de workspaces y límites de repositorio.

## 🚀 Ejecución de Pruebas

Para ejecutar la suite completa con Pytest:

```bash
pytest
```
