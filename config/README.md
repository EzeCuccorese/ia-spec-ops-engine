# Configuración Global (`config/`)

Almacena archivos de configuración global y ejemplos de entornos del sistema.

## 📄 Archivos

- `.env.example`: Plantilla de variables de entorno para configuración pública.
- `.env.secrets.example`: Plantilla para credenciales y datos sensibles.
- `rules-global/`: Reglas globales compartidas del proyecto.
